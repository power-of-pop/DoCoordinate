# Do Coordinate

## サイト概要

### サイトテーマ
ファッションアイテムのコーディネートについてアドバイスを求めたり、意見交換できるコミュニティサイト

### テーマを選んだ理由
もともとファッションに興味があり、服やアクセサリーのコーディネートを考えることが好きでしたが、トレンドアイテムとされているアイテムを今持っている服とどう合わせればいいか思いつかず、コーディネートに頭を悩ませることがありました。<br>
トレンドアイテムの取り入れ方や、今持っている服をどう合わせればより良くなるか、ユーザー同士で意見交換し合えるサービスがあればと考えました。<br>
またビジネスシーンや冠婚葬祭といったフォーマルな場面においての服の選び方に困っている人の役にも立てると考え、このテーマにしました。

### ターゲットユーザ
- ファッションについて少しでも興味や悩みがある人
- 取り入れ方やコーディネートについて、他者と共有したい人

### 主な利用シーン
- どう合わせたらいいのか分からないアイテムがあり、コーディネート例を知りたい時
- デートや結婚式などの予定に合わせたコーディネートのアドバイスをもらいたい時
- 気に入ったコーディネート例があり、誰かに共有したい時
